# 词库（Daily Pulse）

每种语言一个 CSV 文件，Daily Pulse 从里面随机抽 10 个词。

| 文件 | 语言 |
|---|---|
| `nl.csv` | 荷兰语 |
| `bo.csv` | 标准安多藏语 |
| `kk.csv` | 哈萨克语（西里尔） |
| `ru.csv` | 俄语 |
| `es.csv` | 西班牙语 |
| `ja.csv` | 日语 |

## 格式

两列：**词** 和 **中文释义**。

```csv
词,释义
boete,罚款；罚金
weekend,周末
vertrekken,出发；离开
```

就这样。剩下的都是「可以但不必」：

- **表头可有可无**。有的话，第一列表头写 `词 / 单词 / 词条 / word / term` 都认，第二列写 `释义 / 中文 / 意思 / 翻译 / gloss / meaning` 都认，**两列顺序可以反过来**。没表头就默认第一列是词、第二列是释义。
- **分隔符**逗号、Tab、分号、竖线都行，按第一行自动判定。从 Excel 存成「CSV UTF-8」或「制表符分隔」都能直接用。
- **释义可以留空**。留空的词，App 会用一次 AI 请求把这一批一起补齐，补完缓存下来不重复花钱。
- **`#` 开头的整行是注释**，可以拿来分组、写备注。
- **空行**会被跳过。
- **重复的词**只保留第一条。
- 释义里要写半角逗号的话，整格用双引号包起来：`"boete","罚款, 罚金"`。或者直接用中文逗号，省事。
- **编码不用管**。UTF-8（带不带 BOM 都行）、GBK、Windows-1252 都能自动认出来。

多余的列会被忽略，所以你可以自己加「词性」「例句」「来源」之类的列自用，不影响 App。

## 怎么改

**电脑上**：双击用 Excel / Numbers / Google Sheets 打开，改完存回 CSV。

**手机或任何浏览器上**：GitHub 网页里点开文件 → 右上角铅笔 → 直接改 → Commit。GitHub 会把 CSV 渲染成表格，也能搜索。

**删词**：整行删掉。或者不用改文件——在 App 里勾那个词的「熟」，它就永久不再出现了。

**加词**：新起一行。改完 push，App 下次打开会自动拉最新的（拉不到就用上次缓存的那份，离线也能用）。

## 规模

解析是线性的，上万词也没问题——一个 5000 词的文件约 100 KB，解析在几十毫秒量级，之后缓存进 IndexedDB。词库文件不进 `index.html`，不影响 App 本体的体积。
